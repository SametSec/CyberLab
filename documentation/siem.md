# SIEM & Security Monitoring

## Overview

CyberLab includes a centralized Security Information and Event Management (SIEM) workflow based on Wazuh.

The purpose of this component is to collect, analyze and review security-related events generated by authorized laboratory systems. The project focuses on authentication monitoring, log analysis, security-event detection and basic incident-response concepts.

## Monitoring Workflow

1. A monitored system generates an event.
2. The Wazuh Agent collects the relevant endpoint or security data.
3. The event is forwarded to the Wazuh Manager.
4. The Manager analyzes the event using its configured detection logic.
5. Relevant alerts and event details are reviewed through the Wazuh Dashboard.
6. In the Active Response scenario, a matching condition can trigger a configured response.
7. The response result is validated through the firewall state in the laboratory.

## Monitored Activities

- SSH authentication events
- Apache2 access and error logs
- Agent status and endpoint information
- Controlled security test events
- Active Response events using the `firewall-drop` component

## What the Project Demonstrates

The lab demonstrates the basic security-monitoring lifecycle:

```text
Collect → Analyze → Detect → Investigate → Respond → Validate
```

This gives practical context to SIEM concepts by connecting endpoint activity, log sources, centralized analysis and a controlled defensive response.

## Security Scope

This documentation describes an authorized laboratory environment. It is not presented as a production SIEM deployment. Real IP addresses, credentials, certificates, production secrets and other sensitive configuration values are intentionally omitted.
