# SIEM & Security Monitoring

## Overview

CyberLab includes a centralized Security Information and Event Management (SIEM) workflow based on Wazuh.

The purpose of this component is to collect, analyze and review security-related events generated by authorized laboratory systems. The project focuses on authentication monitoring, log analysis, security event detection and basic incident investigation.

## Architecture

```text
                       CyberLab Laboratory Network
                                  |
              +-------------------+-------------------+
              |                   |                   |
         Kali Linux          Ubuntu Server          Windows
       Test / Agent          Manager / Agent         Agent
              |                   |                   |
              +-------------------+-------------------+
                                  |
                           Wazuh Dashboard
```

## Monitoring Workflow

1. Wazuh Agents collect relevant endpoint events.
2. Events are forwarded to the Wazuh Manager.
3. The Manager analyzes the incoming data according to its configured rules.
4. Alerts and event details are reviewed through the Wazuh Dashboard.
5. Authentication and web-server activity can be correlated with the generated events.
6. Active Response can perform a configured action when its triggering condition is met.

## Monitored Activities

- SSH authentication events
- Apache2 access and error logs
- Agent status and endpoint information
- Controlled security test events
- Active Response events using the `firewall-drop` component in the laboratory scenario

## Security Scope

This documentation describes an authorized laboratory environment. Real IP addresses, credentials, certificates, production secrets and other sensitive configuration values are intentionally omitted from the public repository.
