# SIEM & Security Monitoring

## Overview

CyberLab includes a centralized Security Information and Event Management (SIEM) environment based on Wazuh.

The purpose of the SIEM component is to collect, analyze and monitor security-related events generated by systems inside the isolated CyberLab environment.

The project focuses on authentication monitoring, log analysis, security event detection and basic incident investigation.
