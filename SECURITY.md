# Security Policy

## Scope

CyberLab is a personal and educational cybersecurity laboratory. The repository documents authorized experiments involving network security, endpoint monitoring, log analysis, SIEM concepts and incident-response workflows.

## Responsible Use

All testing described in this repository must be performed only on systems that are owned by the tester or for which explicit authorization has been granted.

The repository is not intended to provide access to production systems or confidential infrastructure.

## Sensitive Information

Do not commit:

- Passwords or API tokens
- Private keys or certificates containing private material
- Production credentials
- Unredacted internal network details
- Personal or organizational confidential information

Environment-specific values should be replaced with placeholders before publication.

## Reporting a Problem

For issues affecting this repository itself, open a GitHub issue with enough information to reproduce the problem while avoiding disclosure of sensitive data.
