# Project Screenshots

Screenshots can be added to this directory to document the laboratory visually.

## Recommended Captures

- Wazuh Dashboard overview
- Agent list and connection status
- Agent system information
- SSH authentication events
- Apache2 access/error log events
- Active Response events
- Firewall verification after the response

## Before Publishing

Review every screenshot before committing it to the public repository. Remove or redact:

- Usernames and passwords
- API tokens
- Private keys and certificates
- Internal production addresses
- Personal or organizational information
- Any other confidential information

Screenshots should document the project without exposing sensitive environment details.
